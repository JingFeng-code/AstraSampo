# 平台條款風險紀錄

更新日期：2026-11-17。這份文件記錄開發時讀到的條款和目前的做法，方便公開發布前重新檢查。**它不是法律意見，也不代表某種做法已經合法或被允許。公開發布前應找專業意見確認。**

## 目前各功能的狀況

| 功能 | 做法 | 風險 | 公開發布前要做的事 |
|---|---|---|---|
| YouTube 字幕 | 用非官方套件 `youtube-transcript-api` 讀公開字幕 | **可能違反**自動化存取的限制，可能隨時失效或被封鎖 | 決定保留、移除或取得許可 |
| Bilibili 字幕 | 匿名呼叫未公開的網頁介面 | **可能違反**第 5.6(3) 條；沒有帳號，所以沒有封號風險 | 決定保留、移除或取得許可 |
| YouTube／Bilibili 播放 | 官方嵌入播放器 | 這是條款允許的方式，影片是否能嵌入由平台和作者決定 | 持續使用官方播放器 |
| Gemini 讀畫面 | 把公開 YouTube 網址交給 Google 的官方 API | 由使用者自備金鑰並明確開啟，影片內容由 Google 處理；Gemini 條款仍要確認 | 確認條款並保留明確告知 |
| Bilibili 登入憑證（SESSDATA） | 使用者在設定頁手動貼上、或按「偵測可匯入的瀏覽器」後從自己的瀏覽器讀取；只存本機 `settings.json`，只用來讀需要登入的字幕，不代替使用者登入、也不帶去下載音訊 | 等同帳號登入狀態：憑證外流或共用會讓他人能操作該帳號；第 1.3、5.6(3) 條對自動化取得內容仍有限制 | 公開版要保留明確告知與「移除」按鈕；發布前確認條款風險 |
| Bilibili 沒有字幕時的本機轉錄 | **桌面版內建** `yt-dlp` 與 sherpa-onnx。只有使用者按下「下載音訊並在本機轉成文字」，並在錯誤區塊第二次確認後，才會下載這支影片的音訊到暫存資料夾；轉完立刻刪除、只在本機處理。下載前先檢查長度（上限 90 分鐘）與大小（上限 500 MB），下載不帶 SESSDATA | **可能違反** Bilibili 第 5.6(3) 條（自動程式取得內容）與不得下載內容的限制；只適合有權使用的影片，風險由使用者承擔 | 公開版保留兩段式確認與風險說明；不要改成自動下載或放寬上限 |
| 匯入 SRT／VTT | 使用者提供自己有權使用的字幕 | 權利由使用者負責 | 保留提醒文字 |
| 陪看模式 | 使用者在 AstraTube 裡用官方播放器播放時，擷取 AstraTube 自己的畫面與聲音，交給本機模型；不下載檔案 | 沒有下載，但擷取畫面與聲音仍可能被視為重製內容，屬灰色地帶；只適合個人使用 | 公開發布前一併確認 |
| 本地影片＋本機語音轉文字 | 使用者提供自己有權使用的影片，全程在本機處理 | 不連影片平台；權利由使用者負責 | 確認語音模型與相依套件授權 |

## 已決定不做

- **代替使用者登入，或把帳號密碼交給 AstraTube**：`SESSDATA` 只是使用者自己貼上的既有登入狀態，只用於讀取需要登入的字幕，不代替使用者登入。
- **未經使用者確認就下載線上影片的音訊**：現在只在 Bilibili 確定沒有字幕（或字幕需要登入）時，由使用者按下按鈕並二次確認後才下載；其他錯誤一律不下載，也不放寬長度與大小上限。
- **錄下播放中的聲音或畫面**：陪看模式雖然沒有下載檔案，仍有重製內容的疑慮。

## 可以嘗試的合規方向

- 向 Bilibili（`help@bilibili.com`）或 YouTube 申請書面許可；不一定會有回覆。
- 查 Bilibili 開放平台是否提供字幕介面；開發時沒有查到官方文件。
- YouTube Data API 的 `captions.download` 依社群回報通常只限影片擁有者，可用於使用者自己的影片；需要實際確認。
